What this is

sqtseries stores numbers that change over time and answers questions about them in milliseconds. You give it measurements as they happen — CPU load, room temperature, visitor counts, prices, meter readings — and it keeps them in one SQLite file on your own machine. There is no server to provision and no schema to design.

Two things happen behind the scenes so your questions stay fast without you doing anything. Measurements are stored in monthly partitions, so old data can be dropped whole instead of row by row. And a background task summarises every finished hour into count, sum, minimum and maximum, so a query about last month reads a few dozen summary rows instead of millions of stored points. Because the summary keeps the count and the sum, the average it produces is the real average, not an estimate of one.

The fifteen pages

Metric — the name of something you measure, like cpu.load.
Measurement, or point — one value for one metric at one moment, with optional tags.
Tag — a label that splits a metric into dimensions, like host=web1. A series is a metric plus its tags.
Series — one metric with one exact set of tags. Every stored measurement belongs to exactly one.
Partition — one table per month, named measurements_YYYY_MM.
Rollup — the hourly summary table, rollup_hourly.
Query window — the start and end you ask over.
Port — one of six TCP ports. Five are fixed; the ingest port is chosen at start-up.
Client — the bundled Python Client, or any code that speaks the same JSON.
WAL — SQLite's write-ahead log, which makes every commit crash-atomic.
HWM — high-water mark: a socket queue limit. Reaching it is how backpressure starts.
pts/s — points per second, the unit of ingest rate.

How a measurement travels

One shape, three ways in, one place it lands. ZeroMQ is the high-rate path and is fire-and-forget. HTTP is the path for scripts, browsers and languages with no ZMQ binding. The WebSocket exists for watching, not for writing. A single Python process can skip all of it and open the engine directly.
